## 1. 公式スコア計算式（実測確定）
`合計得点 = 300 × 取得ターン数 + 動作得点 + アイテム得点 + プット得点 + プットダメージ`
- 毎ターン生き残るだけで基礎点 `+300` が入るため、自爆しないことが最優先。

## 2. 絶対厳守ルール（罠と減点回避）
- **絶対踏むな**: `4` (ジオード: -600〜-1000), `12` (奈落: -300〜-600), `10` (岩盤: 通行不可/-10), `1000..8000` (他プレイヤー)。
- **穴 `0` (-20) の再踏破を最小限に**: 既通過マス `0` を踏むと毎回 `-20` 点 + 動作コストを引かれる。袋小路や引き返しを避け、未開拓の土 `2` (+10) やアイテム方向へ一筆書きで進む。

## 3. CMD1 (`gr` vs `gru/grd/grl/grr`) の使い分け（最重要）
- `gru/grd/grl/grr` は **1マス移動してから周囲3×3を取得する** ため、続く CMD2 (`w*`) と合わせて **1ターンで2マス分の回収** ができる。
- **隣接に安全なプラス得点マス (`70-79`, `5-9`, `1`, `3`, `2`) がある時**:
  - 迷わずその方向へ `gru/grd/grl/grr` を使い、続く CMD2 でもさらに次の安全・高得点マスへ `w*` で進む（例: `grr` → `wr` で2連続回収）。
- **隣接が穴 `0` しか無い時（2026-11-20 実測で更新）**:
  - **実測コスト（6試合で公式スコアと完全一致, `bun agent/tools/score-model-check.ts`）**: 静止 `gr` = 動作 -20 ＋ 現在地(穴)への再着地 -20 = **-40**。`gr*` / `w*` = 動作 **-10** ＋ 着地マスの得点（穴なら -20）= **-30**。
  - つまり**穴の上を進む方が静止より得**。目的地方向に安全なマスがあれば必ず `gr*` で進む。静止 `gr` は進める安全マスが1つも無いときだけ。
- **隣接が罠/壁/未知だけの時**: `gr` で静止して観測する。

## 4. CMD2 特殊コマンド（高疲労コスト）の注意点
- 実測により `w*` / `gr*` の動作コストは約 `-10〜-20` と軽いのに対し、`d*` / `p*2w*` / `p*3s*` / `p*3l*` / `kei*` は **1回あたり約 `-200〜-300` 級の非常に高い動作減点（疲労）** が発生する。
- したがって **基本は `w*`（`wu/wd/wl/wr`）で低疲労・堅実に回収** する。
- 特殊コマンドは **高疲労を上回る明確なリターンがある例外時のみ** 使う:
  - 四方を穴 `0` や罠 `4/12/10` に囲まれて通常移動では大減点が確定する時、`kei*` で安全な既知/未踏地帯へ飛び越える。
  - 遠くに高得点群（ジオーメタル `70-79` や化石 `5-8`）が確実に見えていて、穴を踏まずにショートカットできる時。
  - 注意: `pr3sr` / `pu3lu` 等は時計回り90度方向へ移動するため着地先が罠でないか必ず確認すること。

## 5. マップ解析ツールの活用
- 毎ターン与えられる `evaluate_candidates` 要約（各候補手の安全判定・即時期待値・BFS最良ルート）を根拠に判断する。
- 穴が続く時は、経路全体で既訪の穴が少ない観測地点を選ぶ。同条件なら、一直線の奈落が2マス以上続く延長上より、開けた側の未探索マスを先に観測する。延長上も観測するまでは未知で、奈落と断定しない。

## 8. room719 (2026-11-20 15:08, 1579ターン, 公式570655) 実測 — 穴553回・罠43回の原因
- **罠ヒット43回は「古い記憶で、実際は穴(0)だったマス」への進入が原因ではない**（ログ全数照合で一致0件）。43回はすべて**真に未知/誤ったマス**（ワープ直後の座標系切替や、盤面が観測間で変わった）へ `gr*`/`w*` で入ったもの。ソルバーが見る地図のタイル値は直前の観測と常に一致している。
- **穴(0)踏破553回のうち約254回は「記録は 71/77 等のプラス、実際は穴」**。これは記憶の古さではなく**スコア済み・回収済みのマスが穴になる/穴がアイテムに見える仕様**。逆算プランでも約30%は穴になるため、高得点帯を往復して回収する作戦では一定量の穴踏破は避けられない。**穴は「目的地」にせず通過点として使い、回収したマスには戻らない**のが有効。
- **putは一度も発動しなかった**（Put 0点 / 敵の目撃記録もゼロ）。方針「5マス以内で敵を追う」に対し、ソルバーの put は**直前の観測グリッドに隣接表示された敵**しか対象にしないため、敵が 3x3 の外に出ると追跡が止まる。改善はハーネス（`worldMap.getEnemySightings()` と put 候補の拡張）側が必要。
- **1試合の実時間は 3時間21分**（平均 7.6 秒/手、p90 2.1 秒）。1579 ターン時点で残り 0 ターン（HTTP 500 終了）。**ターン数上限は約 1579** と推定。
- 会話メモ・サブ委託（#4〜#13 のタイル調査）は毎回 docs にしか残らず、ソルバーの通常手（main 98% が continue）には反映されなかった。作戦変更（plan）は 349 手で着実に効いていた（目標マスへ最短移動）。
