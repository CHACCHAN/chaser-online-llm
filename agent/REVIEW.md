  - 対応（2026-11-23）: 空き時間の学習は、人数が自分だけのルーム（sim-profiles の players の上限が 1）では、目的に当てた・当てられた得点があるモデル（ハンター・ガーディアンなど）を育てない（`src/sim/lab.ts` の `idleStyles`）。
- [対応済み] **統計の「作った地図と本物の地図の違い」がルーム違い。** ルーム3の学習なのに、比べている本物の地図はルーム720の3枚でした（ルーム3の本物の地図は無いと思われます）。比べる対象が学習の部屋と合っているか確かめてください。ルーム3は `sim-profiles.json` の `_note` に実測が書いてあるだけで、地図の形の比較ができていません。

- [対応済み] **`agent/tools/*.ts` の型エラー80件。** `noUncheckedIndexedAccess` による `possibly undefined` が中心です。`bun run typecheck` の対象から外すか、直してください。
  - 対応（2026-11-23）: `bun run typecheck` の対象から外し、`bun run typecheck:tools`（`tsconfig.tools.json`、`noUncheckedIndexedAccess` なし）で別に確かめる。緩めても 27 件残っている（ツールの持ち主のエージェントが直す）。

  - 対応（2026-11-23）: 当てる手は、このターンに自分の観測で見えた隣の敵にだけ出す（Webマップから位置合わせした敵の位置は使わない。`WorldMap.getLocalEnemySightings`）。
- [対応済み] **ワープの周回で足踏みし、狙う敵に当て続けられる（#19、フレーム 47〜148）。** 「出口のワープへ（行き先の分かっているワープを通る）」が 4 ターンごとに同じ場所へ戻り、そのたびに −4755 点です。100 ターンで約 −80000 になりました。同じ位置に戻ってくるのに点が増えない周回を検出して、別の行動に切り替える仕組みが必要です。
